# 배선

## A. XIAO ESP32S3 Sense

```text
 5V 3A 어댑터
   │(+)                                   (−)│
   ├──[1000µF]────────────────────────────────┤  ← 서보 레일 바로 옆
   │                                           │
   ├── 서보 PAN  V+ (빨강)     GND (갈색) ─────┤
   ├── 서보 TILT V+ (빨강)     GND (갈색) ─────┤
   ├── WS2812B  5V            GND ────────────┤
   ├── 부저(+)  ── 부저(−) ─ C│NPN│E ──────────┤
   │                          B                │
   └──▶|── SS14 ──▶ XIAO 5V    XIAO GND ───────┘  (공통 GND 필수)

 XIAO 핀         연결
 D0 (GPIO1)  ── 서보 PAN  신호 (주황)
 D1 (GPIO2)  ── 서보 TILT 신호 (주황)
 D2 (GPIO3)  ──[330Ω]── WS2812B DIN
 D3 (GPIO4)  ──[1kΩ]─── NPN 베이스 (부저)
```

| XIAO 핀 | GPIO | 연결 | `board_pins.h` |
|---|---|---|---|
| D0 | 1 | 팬 서보 신호 | `PIN_SERVO_PAN` |
| D1 | 2 | 틸트 서보 신호 | `PIN_SERVO_TILT` |
| D2 | 3 | WS2812B DIN (330Ω 직렬) | `PIN_STATUS_LED` |
| D3 | 4 | 부저 트랜지스터 베이스 (1kΩ) | `PIN_BUZZER` |
| 5V | - | 외부 5V (SS14 다이오드 경유) | - |
| GND | - | 공통 GND | - |

카메라는 Sense 확장보드 B2B 커넥터로 연결되어 별도 배선이 없습니다. SD 슬롯(GPIO 7·8·9·21)은 사용하지 않습니다.

## B. AI-Thinker ESP32-CAM

| ESP32-CAM 핀 | 연결 | 비고 |
|---|---|---|
| IO14 | 팬 서보 신호 | SD 미사용 전제 |
| IO15 | 틸트 서보 신호 | 부팅 시 짧은 떨림 가능 (스트래핑 핀) |
| IO13 | WS2812B DIN (330Ω) | |
| IO2 | (선택) 부저 | 기본 비활성. 쓰면 베이스에 10kΩ 풀다운 필수 |
| 5V / GND | 외부 5V | **3.3V 핀 급전 금지** — 브라운아웃 |

업로드: ESP32-CAM-MB 에 꽂아 USB 로 업로드 (IO0-GND 자동 처리). 업로드 중에는 외부 5V 를 분리하세요.

## 전원 설계 규칙

1. **서보는 ESP32 3.3V 레귤레이터에서 절대 급전하지 않습니다.** 5V 레일에서 직접 받습니다.
2. 1000µF 를 서보 커넥터 가까이 두어 기동 전류 스파이크를 흡수합니다 (Wi-Fi 송신 + 서보 기동이 겹치면 리셋됨).
3. 모든 GND 는 한 점(전원 분배 기판)으로 모읍니다.
4. XIAO 를 USB-C 로 PC 에 연결해 업로드할 때 외부 5V 가 USB 로 역류하지 않도록 SS14 를 둡니다.
5. 서보 신호는 3.3V 로직이지만 MG90S/SG90 은 대부분 정상 인식합니다. 인식이 불안정하면 74AHCT125 로 5V 레벨 변환.
6. WS2812B 는 5V 급전 + 3.3V 데이터로 대부분 동작하지만, 깜빡임이 있으면 LED 를 3.7V 이하로 낮추거나(다이오드 1개 직렬) 레벨 변환합니다.

## 팬 회전과 케이블

- 기본 팬 범위는 10°~170° (`PAN_MIN_DEG`/`PAN_MAX_DEG`) → 케이블에 **약 80mm 여유 루프**를 두면 슬립링 없이 충분합니다.
- 360° 연속 회전이 필요하면 6선 슬립링을 팬 축 중앙에 두고, 연속 회전 서보 또는 스테퍼로 바꿔야 합니다 (펌웨어 수정 필요).
